# Portfolio simplification — 19 October 2026

## Observed before the change

Opened the live homepage and all six project routes in the browser. Each secondary project showed 19 images/diagrams and 25 buttons, with essentially the same drawing headings. The courtyard page added a seven-stage drawing sequence. Large overlaid headlines, repetitive diagrams and many controls competed with project content. Screenshots of the homepage, courtyard and shadow-house page were visually inspected.

## Reference inspection

Read the John Pawson architecture index at https://www.johnpawson.com/architecture and Norm Architects' project index at https://normcph.com/project_category/architecture/. Useful structural patterns: clear project names, direct navigation and concise descriptions. This was a focused inspection of those pages' structure and content, not a claim to have visually tested all their interactions.

## Change

Replaced active homepage and all project presentations with a restrained static gallery. Kept existing identity and Arabic RTL support. Removed animated drawings, comparison controls, repeated technical headings, promotional filler and simulated inquiry submission from the active interface. Preserved explicit demonstration/reference-image labels. Removed invented location, floor area and project date metadata from visible presentation. Each study has a distinct cover selection.

## Pre-publication checks

- JavaScript syntax checks passed for viewer and legacy-route redirect.
- Parsed all eight HTML pages; each has one H1 and every local image, script, stylesheet and navigation target exists.
- Downloaded image variants, inspected a contact sheet and corrected inappropriate cover selections.
- Images have intrinsic dimensions and responsive variants. Mobile CSS uses one column at 680px and below.

Live verification will be recorded after publication. No mobile browser result or performance score is claimed by these source checks.
